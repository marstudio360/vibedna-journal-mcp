# Rules template

Create a journal named `RULES_JOURNAL.md` (or any `<NAME>_RULES_JOURNAL.md`, or `OWNER_SAID_JOURNAL.md`) and write one dated line per rule,
starting with `- 2026-...`. When your AI is about to do something that shares the words of a rule, the journals mod
shows the line and stops once; the same action passes on retry.

```markdown
# Rules

- 2026-03-05: Plans are ship-now steps: what ships today, what ships next. Calendar plans ("30/60/90 days") are not used here.
- 2026-03-06: Every price shown to customers comes from the price list file, so a price is changed in one place.
- 2026-03-09: Customer mails go out only after a person approves the draft, so every send has a name behind it.
```

Tips: write the rule with the words people will use when they start the work; add the reason in the same line;
keep each line to one rule.
